privacy

what it remembers

Last updated October 24, 2026. This is how the bot works today.

owaua remembers your conversations with it, useful notes, and your settings, so the next reply isn’t starting from nothing. It doesn’t keep a background log of the rest of the room.

what this is for

This is for the official owaua Discord bot, the one you invite from this site. Client id 1442127404607737999. The website and the Discord server are run by the same person.

Discord has its own privacy policy, and that still applies. If you run a copy of the code yourself, that copy is yours. This page is only about the official bot.

Using the bot also means you agree to the terms.

how to reach me

Questions and deletion requests can go to ckazros@owaua.com, Discord ckazros, or the Discord server. If you want a specific account looked up, include your Discord user id. Please don’t paste private chats into a public channel.

what it keeps

Only what it needs to answer you, and to remember a little so the next reply has something to go on.

  • who you are on DiscordYour user id, and the server and channel ids needed to keep conversations separate. DMs have their own conversation scope. Display names come with the message Discord already sent.
  • the conversationMessages you send through mentions, replies, commands, or DMs, and the bot’s answers. Memory is separate for each server, channel, and person. It doesn’t save ordinary room chatter as shared context, and it ignores other bots.
  • attachments and saved documentsImages, documents, recordings, and video references you deliberately send can go to xAI for the feature you requested. A temporary document upload is deleted after use when cleanup succeeds, with a one-hour provider expiry as a fallback. /knowledge add deliberately saves a document at xAI until you remove it with /knowledge forget or /knowledge clear. Local library records keep the filename, size, and provider file id, not the document bytes.
  • your settings and notesYour persona and reply language follow your account across servers and DMs. Notes, conversation memory controls, and document libraries belong to your own conversation scope. Notes stay until you delete them. These settings survive restarts.
  • a usage markDaily media reservations and job records include Discord scope ids, the request state, provider job ids when available, and temporary result links. They enforce allowances and let submitted video jobs resume checking after a restart. Ordinary AI requests have a short cooldown and a limit on simultaneous work.

why

So it can reply, remember what you told it, and keep the voice and language you asked for. So one person can’t wear it out. So it can play a song, speak, transcribe a recording, or make media you asked for.

I don’t sell any of this. There are no ads. Your DMs are not a mailing list.

where it lives

On the machine that runs the bot, in a local database. Your history is keyed by server, channel, and you. Two people in the same channel have separate histories. The same person in two channels has two. Document library metadata and media job records are stored locally too.

By default, up to 16 recent exchanges can be used as context, within a 32,000-character budget. The bot can also retrieve relevant older exchanges and your saved notes from that same scope. Other people’s conversations are not included.

Conversation history is kept for up to 180 days, with up to 1,000 exchanges per scope by default. Notes stay until you forget or clear them. Persona and language settings stay until changed or reset. Saved library documents have their own deletion controls.

Please don’t send passwords, tokens, or anything you wouldn’t want saved. If you already did, use /reset or /memory clear for your history and notes here, remove any saved library document separately, or write to me.

who else sees it

Discord already has the message. That’s their platform.

To write a reply, the bot sends your current prompt, relevant recalled context, saved style and language preferences, and requested attachments to xAI. Text requests ask xAI not to store the response; that is not a promise about every kind of provider retention. Web and X searches, hosted code execution, and read-only integrations you choose can send the request data those features need to the services involved. Local memory controls do not call a model.

Music sends the song name or SoundCloud link it needs to find and play the track. Making an image or video sends the prompt you confirmed, and any references, to xAI. I’m not Discord, xAI, or SoundCloud. Their policies apply to what passes through them.

voice and recordings

/voice join sends only the starter’s microphone audio to xAI. Everyone in the voice channel can hear the bot’s replies. These live voice sessions don’t read or save your conversation history or document library, and the bot doesn’t write raw microphone audio or realtime transcripts to its logs.

A recording you attach to a chat request is different: it is transcribed, and that transcript becomes part of the conversation when used to ask a question. A standalone /transcribe request returns files without saving a conversation. Speech and transcription still involve xAI.

how long

History stays until it falls off the exchange limit, expires after 180 days, you clear it, or I delete it for you. Saved notes, persona and language settings, and library documents have separate deletion controls. Media request and quota records persist until the operator deletes them; temporary result links can expire earlier at the provider. Music queues disappear when the bot restarts.

Backups of the host can hold a copy for as long as those backups exist. Treat that file like private chat, because it is.

your choices

If you don’t want a record, don’t talk to it. Leaving a server stops new memory for you there. It does not, by itself, wipe what’s already stored.

/memory pause stops reading and saving conversation memory here until /memory resume. /reset or /memory clear deletes your history, archive, and notes in this scope. /memory forget removes a saved note and its recorded source exchanges; paraphrases in other answers may remain. These controls do not delete your persona, language choice, or document library. Use /knowledge forget or /knowledge clear for saved documents. These history controls do not erase media job records; write to me if you need those removed.

If that isn’t enough, email ckazros@owaua.com with your Discord user id. Say whether you mean DMs, a server, or both. Messages still sitting in the Discord channel are Discord’s, not ours.

You can also stop using the bot, or kick it. Kicking it stops new collection in that server. It does not automatically delete the file.

this website

These pages are static. The menu and contact link don’t set cookies, and this version no longer loads the former Pinterest tracking tag. The host still keeps ordinary request logs. Contact is just email.

age

You need a Discord account, and you need to be old enough for Discord. That means 13 or older. Please don’t use the bot if you’re under 13. The default voice is casual, and it swears. There is no adult mode. Explicit sexual content stays off, whatever voice you pick.

if you run it yourself

Self-hosting means your database, your keys, your users, and your own privacy page. The official bot is the one invited from this site. I can change models, limits, and where the file lives. If that changes what gets collected in a way that matters, this page will say so.
