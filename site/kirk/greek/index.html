προσκάλεσέ τον

ένα bot του Discord με το οποίο μπορείς να μιλήσεις

Το site είναι μικρό. Το bot είναι το κομμάτι που μετράει.

το bot που κάθεται στον server σου

Σωπαίνει μέχρι να του μιλήσεις. Μετά μπορεί όντως να βοηθήσει.

Κάνε του mention, απάντησε σε κάτι που είπε, ή στείλε του DM. Θυμάται τη δική σας συζήτηση σε αυτό το κανάλι, όχι των υπολοίπων. Μπορεί να αλλάξει ύφος, να απαντά στη γλώσσα σου, να ψάξει κάτι, να φτιάξει εικόνα ή σύντομο βίντεο, να μιλήσει μαζί σου σε voice, ή να βάλει ένα τραγούδι.

έλα στο Discord προσκάλεσε το owaua

Οι slash εντολές δουλεύουν. Και μια τελεία, π.χ. .ask τι ώρα είναι. Αν μια εντολή είναι ιδιωτική, η απάντηση έρχεται σε DM, οπότε άφησέ τα ανοιχτά. Το μήνυμα που έγραψες στον server μένει ορατό.

01

τι κάνει

Του μιλάς όπως θα μιλούσες σε κάποιον στον server. Η φωνή και η γλώσσα είναι δικές σου, όχι του δωματίου.

περιμένει να του μιλήσεις

Δεν πετάγεται σε κάθε μήνυμα. Κάνε του ping, απάντησε σε κάτι που είπε, ή στείλε DM. Mention, /ask ή .ask, όλα δουλεύουν. Αφήνει τα άλλα bot ήσυχα και δεν κρατάει αρχείο για τους υπόλοιπους στο κανάλι.

θυμάται τη συζήτησή σας

Σε αυτό το κανάλι, η συνομιλία σας μένει δική σου. Τα πρόσφατα είναι εκεί. Τα παλιότερα μπορεί να τα ξαναβρεί, για περίπου έξι μήνες. Αν του πεις κάτι να το κρατήσει, μπορεί να σώσει μια σημείωση μέχρι να τη σβήσεις. Ο διπλανός έχει τη δική του μνήμη.

μπορεί να ακούγεται όπως θες

Από μόνο του μιλάει σαν φίλος. Χαλαρά, και βρίζει. Αν δεν είναι αυτό το κλίμα, άλλαξέ το: πειρατής, ρομπότ, μάγος, ντετέκτιβ, δάσκαλος, ή μια σύντομη δική σου περιγραφή. Η επιλογή σε ακολουθεί. Δεν αλλάζει το bot για τους άλλους.

η γλώσσα σου, όχι όλου του server

Δοκίμασε .language Hungarian. Από εκεί οι απαντήσεις σε σένα είναι σε αυτή τη γλώσσα, και σε άλλους server, στα DM, και στο επόμενο voice. Το .language auto ξαναακολουθεί το πώς γράφεις.

ένα τραγούδι, αν θες

Μπες σε voice και δοκίμασε .music με έναν τίτλο, ή κόλλα έναν σύνδεσμο SoundCloud. Τα επόμενα περιμένουν. Παύση, συνέχεια, skip, stop, από το ίδιο κανάλι. Όχι playlists, live, ή σύνδεσμοι YouTube.

μπορεί να ψάξει, και να διαβάσει ό,τι στέλνεις

Μια μικρή ερώτηση μπορεί να πάρει μικρή απάντηση. Μια μεγαλύτερη, μια κανονική εξήγηση. Μπορεί να ψάξει στο web και στο X, να δει μια εικόνα, να διαβάσει PDF ή κώδικα, και να σου γυρίσει αρχείο ή ένα απλό γράφημα.

εικόνες, βίντεο, και μια κανονική φωνή

Ζήτα εικόνα ή σύντομο βίντεο, ή στείλε ένα και πες τι να αλλάξει. Σου δείχνει πρώτα το prompt. Δεν φτιάχνει τίποτα μέχρι να πεις ναι. Το /speak διαβάζει κείμενο. Το /transcribe γράφει μια ηχογράφηση. Το /voice join είναι κανονική συζήτηση στο voice.

02

πώς του μιλάς

Κάθε slash εντολή δουλεύει και με τελεία. Η φωνή, η γλώσσα, η μνήμη και τα αρχεία είναι δικά σου. Η μουσική ελέγχεται μόνο αν είσαι στο ίδιο voice.

/help

Η σύντομη εκδοχή, όταν το ξεχνάς.

/ask

Ρώτα κάτι. Μπορείς να επισυνάψεις εικόνα, έγγραφο, ηχογράφηση, ή βίντεο για αλλαγή.

/persona set

Διάλεξε χαρακτήρα, ή περιέγραψε τη φωνή. Το /persona reset φέρνει πίσω τη συνηθισμένη.

.language Hungarian

Απαντήσεις σε σένα, σε αυτή τη γλώσσα. Το .language auto ακολουθεί ξανά το μήνυμά σου.

.music

Βάλε ένα τραγούδι. Μετά queue, pause, resume, skip ή stop.

/memory view

Δες τις σημειώσεις σου. remember, forget, pause και resume κάνουν τα υπόλοιπα. Το pause δεν σβήνει.

/reset

Σβήσε το ιστορικό και τις σημειώσεις σου σε αυτό το κανάλι. Φωνή, γλώσσα και έγγραφα μένουν.

/knowledge add

Κράτα ένα έγγραφο για μετά, σε αυτό το κανάλι. Το /ask library:true το χρησιμοποιεί.

/voice join

Μιλήστε στο voice. Ακούει μόνο όποιον το ξεκίνησε. Όλοι στο κανάλι ακούνε τις απαντήσεις.

/speak

Κείμενο σε ήχο, ή ηχογράφηση σε κείμενο.

03

τα όρια

Υπάρχουν για να μην ανεβάζει ένας άνθρωπος τον λογαριασμό, και για να μπορώ να το αφήνω ανοιχτό. Είναι όρια. Η χρήση μού κοστίζει λεφτά έτσι κι αλλιώς.

5s

δώσ' του ένα δευτερόλεπτο

Περίπου πέντε δευτερόλεπτα ανάμεσα στα αιτήματά σου, και λίγες συζητήσεις ταυτόχρονα.

2

οι εικόνες και τα βίντεο έχουν όριο

Δύο εικόνες και ένα βίντεο τη μέρα για σένα. Ένας server μοιράζεται πέντε εικόνες και τρία βίντεο. Μηδενίζει τα μεσάνυχτα, ώρα Βουδαπέστης. Επιβεβαιώνεις πριν ξοδευτεί.

20

μουσική και voice μένουν μικρά

Ένας player ανά server, μέχρι 20 τραγούδια στην αναμονή, κομμάτια SoundCloud κάτω από μία ώρα. Μια φωνητική συζήτηση κρατάει το πολύ δέκα λεπτά. Σταμάτα τη μουσική πριν μιλήσεις.

Κάνει και λάθη. Αν μια απάντηση μετράει, έλεγξέ την, ή ρώτα έναν άνθρωπο.

04

τι κρατάει

Οι συζητήσεις σας, οι σημειώσεις που του ζήτησες να κρατήσει, και ρυθμίσεις όπως η φωνή και η γλώσσα. Μένουν στο μηχάνημα που τρέχει το bot. Όταν απαντά, τα χρήσιμα κομμάτια πάνε στην xAI. Ένα έγγραφο που διαλέγεις να σώσεις μένει εκεί μέχρι να το σβήσεις. Τίποτα από αυτά δεν πουλιέται, και δεν υπάρχουν διαφημίσεις.

Η μεγάλη εκδοχή είναι η πολιτική απορρήτου. Αν το προσκαλέσεις, δέχεσαι και τους όρους.

05

ερωτήσεις

Απαντά σε κάθε μήνυμα;

Όχι. Κάνε του ping, απάντησέ του, χρησιμοποίησε εντολή, ή στείλε DM. Τον υπόλοιπο χρόνο σωπαίνει.

Γιατί δεν απάντησε;

Κοίτα αν το ping ή η εντολή έφυγε όντως, και δώσ' του μια στιγμή. Μια μπάρα που κινείται σημαίνει ότι δουλεύει. Αν μείνει ήσυχο, κοίτα τα όρια από πάνω.

Μπορώ να αλλάξω πώς ακούγεται;

Ναι. /persona set description:Talk like a pirate, ή έναν έτοιμο χαρακτήρα. Ισχύει μόνο για σένα. Το /persona reset φέρνει πίσω τη συνηθισμένη φωνή.

Η μουσική παίζει όντως;

Ναι, για κομμάτι SoundCloud που μπορεί να φτάσει. Μπες στο voice, μετά .music και τίτλος ή σύνδεσμος. Οι σύνδεσμοι YouTube και οι playlists δεν παίζουν.

Μπορώ να εμπιστευτώ κάθε απάντηση;

Όχι. Μπορεί να ακούγεται σίγουρο και να έχει άδικο. Αν μετράει, έλεγξέ το, ή ρώτα έναν άνθρωπο.
