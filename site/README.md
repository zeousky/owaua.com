# the site

`index.html` is the English home. Other languages live in `french/`, `german/`, `greek/`, `hungarian/`, `italian/`, `polish/`, `romanian/`, and `ukrainian/`.

`privacy/`, `terms/`, and `partnerships/` are their own pages. Shared CSS, scripts, fonts, and pictures are in `assets/`. `404.html` is the missing page. `assets/archive/` is old stuff the site does not use.

Keep the URLs. A folder is served from its `index.html`.

Partner text is [`partnerships/ergo.json`](partnerships/ergo.json). How to edit it is in [`partnerships/README.md`](partnerships/README.md).
